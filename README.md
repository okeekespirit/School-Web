# 🎓 Anglican SHS Smart Portal

An advanced digital school management and learning system designed to modernize education through smart technology, cloud learning, and AI-powered student support.

---

## 🌟 Overview

The Anglican SHS Smart Portal is a responsive web-based platform that combines:

- 📚 Digital curriculum resources
- 📊 Academic dashboards
- ☁️ Cloud learning storage
- 🤖 Ebony AI student assistant
- ⚽ Student activities management
- 📢 School announcements & support
- 🔐 Smart login system

The project is designed to simulate a modern Learning Management System (LMS) similar to Google Classroom, Moodle, and PowerSchool.

---

# 🚀 Features

## 🔐 Authentication System
- Student login interface
- Personalized dashboard sessions
- Firebase-ready authentication structure

## 📊 Smart Dashboard
- Attendance analytics
- GPA tracking
- Assignment monitoring
- Upcoming exams
- Academic performance overview

## 📚 Curriculum Portal
- Subject resources
- Learning materials
- ICT & coding lessons
- WAEC/WASSCE support
- AI-assisted study help

## ⚽ Activities Center
- Sports management
- Coding club
- Debate society
- Creative arts programs
- Student leadership activities

## ☁️ Cloud Storage
- Upload assignments
- Share notes
- Store projects
- Firebase cloud integration ready

## 🤖 Ebony AI Assistant
The built-in AI assistant helps students:
- Understand lessons
- Research subjects
- Access learning support
- Get academic guidance
- Receive instant responses
